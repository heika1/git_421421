## Як працювати з Git

1. **Клонувати репозиторій:**
```
git clone <репозиторій>
```
2. **Переключитися на гілку розробки:**
```
git checkout develop
```
3. **Створити нову гілку для завдання:**
```
git checkout -b feature-ім'я_фічі
```
4. **Зробити зміни та закомітити:**
```
git add .
git commit -m "Опис змін"
```
5. **Злити зміни в `develop`:**
```
git checkout develop
git merge feature-ім'я_фічі
```
6. **Відправити зміни на GitHub:**
```
git push origin develop
```
